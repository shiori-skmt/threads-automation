# 楽天マラソン便乗「毎月買うものリスト」投稿(一般アカウント・定例)

2026-11-04 ユーザー指示: 「マラソンのたびに投稿したい」。マラソンが始まる日に、このリストをツリーで投稿する。

## いつ投稿するか
- 開始日・時間は、ユーザーが教えてくれたものを使う(2026-11-04は「20:00開始・22:00に投稿」)。教えてもらえない場合は、ユーザーに日付を聞く(日付は推測しない)。
- 通常の6枠(朝・昼・15時台・夕方・20時台・夜)とは別の追加投稿。ドラフトは `state/approved_drafts/{日付}-marathon.md`(投稿後は `posted_drafts/`)。
- 投稿は `/home/user/post_chain.py`(環境リセットで消えたら、下の手順で作り直す)で、1件目→リプライ4件を順に、直前の投稿へのリプライとして投稿する。投稿前に、最新投稿に「毎月買うものリスト」が無いことを確認する(重複防止)。

## 作り方(毎回)
1. 4商品を楽天商品検索API(itemCode指定)で取り直し、**価格・アフィリエイトリンクを最新にする**(価格は変わる。リンクは毎回取り直す)。
2. 1件目(本文): 「毎月買うものリスト🛒/楽天マラソンに合わせて、まとめて買う派です」+ ✔️ の4行(商品名+価格)+「買い忘れがないように、メモしておく📝/みんなの「毎月リピートしてるもの」も気になる👀」+ ハッシュタグ `#楽天マラソン #毎月買うもの #リピート買い`。
3. 2〜5件目: 各商品を1件ずつのリプライ(商品名・アフィリエイトリンク・PR)。それぞれ直前の投稿へのリプライにして、ツリーにする。
4. 「楽天マラソン」と表記する(「お買い物マラソン」ではない)。開始日が5と0のつく日のときは、1件目の先頭に PIPELINE の5/0の日の行を足してよい。
5. 禁止: 安い/お得/最安/セール/期間限定/クーポン/〇円オフ、他との比較、効能表現(サプリ・プロテイン)。
6. ユーザーの商品が増えた/変わったときは、このファイルのリストを更新する(ユーザーに聞く)。

## 環境リセット時の `post_chain.py`
トークンは `/home/user/run_check.sh` の `THREADS_TOKEN_R`、ユーザーIDは一般アカウント。`reply_to_id` に直前の投稿IDを付けて、5件を順に `threads` → `threads_publish` で投稿する(各ステップの間に3秒あける)。
